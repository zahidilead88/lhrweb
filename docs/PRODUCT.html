Product Overview
§1

LHRWEB is a full-stack website builder platform for a digital agency. It combines a public-facing agency website, a client-facing visual page builder, a multi-role admin CMS, and a Stripe-powered subscription system into a single monorepo.

The centrepiece is a Figma-like visual canvas editor — a browser-based design tool where users create pages using frames, elements, shapes, and AI-generated content, then export or publish their work directly.

Who uses it
End clients (subscribers) build their own sites using the visual builder. Agency admins manage the platform via the CMS. The public visits the agency website at the root domain.
What it produces
Publishable websites (hosted at subdomains or custom domains), exportable HTML/CSS, Next.js, or Laravel code packages — all generated from the visual builder's element tree.

Visual Builder — Overview
§8

The visual builder is the core product — a browser-based design tool heavily inspired by Figma's interaction model. It lives at /builder and is backed by a 3,200-line React page (app/builder/page.tsx) plus 20+ dedicated components.

Two canvas modes
Free Canvas (default) — an infinite artboard where users place Frames and free elements. Block editor — a legacy sequential section editor used by the admin CMS.
Data model
Projects are stored as BuilderProject MongoDB documents. Each project has pages, and each page stores frames (artboards) plus a flat element tree.
Auto-save
Canvas state is auto-saved to the API every few seconds when changes occur. A save-status indicator (green/yellow dot) shows current state.
Undo / Redo
Snapshot-based undo system. Every destructive action (move, resize, delete, add) saves a snapshot. ⌘Z restores the previous state.
Canvas System
§9
Infinite canvas

The canvas is an HTML div with a CSS transform: translate + scale applied. The viewport pans (Space+Drag or middle-mouse) and zooms (Ctrl+Scroll, pinch) without limit. Zoom range: 5% → 800%.

Rulers

Horizontal and vertical Canvas-rendered rulers (using the HTML5 Canvas API) draw tick marks and labels that update in sync with pan/zoom. The ruler corner anchors at the intersection.

Dot grid

A CSS radial-gradient background grid toggleable via the G button in the toolbar. The grid pans and scales with the canvas at zero DOM cost.

Snap guides

While dragging elements, red alignment lines appear when the element's edges or center align with another element's edges or center. Computed in real time using a 5px snap threshold.

Rubber-band selection

Click-drag on empty canvas area draws a selection rectangle. All elements whose bounding boxes intersect the rectangle are added to the multi-selection.

Context menu

Right-click on canvas opens a portal-rendered context menu with: Copy, Paste (Figma or internal), Duplicate, Bring to Front/Forward, Send Backward/Back, Delete.

Frames

  • Resize frame by dragging its edges/corners

  • Publish frame → assigns it as a page in the live site
  • Convert frame to reusable section (saves HTML + CSS to the sections library)
  • Delete frame
Elements
§12

Elements are the building blocks placed inside frames or on the free canvas. The element tree (ElementNode[]) is a recursive structure — every element can have children.

ElementNode structure
interface ElementNode {
  id: string
  tag: HTMLTag // div, p, h1–h6, img, a, button, form…
  content?: string // text content for leaf nodes
  attrs?: Record<string, string> // href, src, alt, data-svg…
  styles: { desktop, tablet?, mobile? } // responsive overrides
  children: ElementNode[]
  layout?: FreeLayout // canvas position & sizing
  animation?: AnimationConfig // motion & interaction config
}
FreeLayout — canvas position
interface FreeLayout {
  x, y: number // canvas coordinates
  width: number
  height?: number
  rotation?: number // degrees
  zIndex?: number
  widthMode?: "fixed" | "hug" | "fill" // Figma sizing modes
  heightMode?: "fixed" | "hug" | "fill"
  constraints?: { horizontal, vertical } // resize behaviour
}
Available element types
Layout
Section, Flex container, Grid container, Div
Typography
H1–H4, Paragraph, Span, Blockquote
Navigation
Nav, Header, Footer, Link
Media
Image, Video, SVG embed, Pen path

Form, Input, Textarea, Select, Checkbox, Button
Shapes
Rectangle, Ellipse, Line, Arrow, Polygon (hexagon), Star
Styles — the Styles type

Each element holds three responsive style objects: desktop (required), tablet, mobile (both optional overrides). The Styles interface covers 100+ CSS properties across: layout, sizing, spacing, typography, background, border, effects, position, overflow, transform, animation, and shapes (clipPath).

Drag-and-drop from panel

Elements can be dragged from the Add Panel (left sidebar) directly onto the canvas. The drop position is computed from the mouse location relative to the canvas transform, and the element is routed to the correct frame if dropped inside one.

Auto-Layout
§14

When a frame's layoutMode is set to Horizontal, Vertical, or Grid, its children switch from absolute-positioned react-rnd elements to a CSS flex/grid layout — exactly matching Figma's auto-layout behaviour.

None (default)
Children are absolutely positioned and freely draggable via react-rnd.
Horizontal / Vertical
Children rendered as CSS display: flex with configurable gap and padding. Alignment controlled via justify-content / align-items.
Grid
Children rendered in a CSS grid with configurable column count and gap.

Auto-layout properties include: per-side padding (top/right/bottom/left), gap, justify-content, align-items, and grid column count. The Frame properties panel exposes all of these with live preview.

Layers Panel
§15

The left sidebar shows a collapsible tree view of all frames and their child elements. Features:

  • Hierarchical display with expand/collapse for grouped elements
  • Click to select element on canvas (syncs with canvas selection)
  • Drag-to-reorder within the same parent
  • Rename via double-click
  • Visibility toggle (eye icon) — hides element without deleting
  • Lock toggle — prevents accidental selection/move on canvas
  • Frame list at the top level, with children nested beneath
Figma Copy-Paste
§16

Select elements in Figma, press ⌘C, then press ⌘V in the builder canvas — the selected Figma elements appear as fully editable builder elements.

How it works

Figma writes its own proprietary MIME type (application/vnd.figma.clipboard.v5+json down to v2) to the clipboard. The builder reads these types via a paste event handler (ClipboardEvent.clipboardData.getData()) — which requires no browser permission.

Critical implementation detail: All clipboard data must be read synchronously in the paste event handler before any await, because browsers recycle the DataTransfer object when the event handler returns. The builder reads all raw data first, calls e.preventDefault() synchronously, then processes data asynchronously.

What gets converted
Node types
TEXT → heading/paragraph; RECTANGLE, ELLIPSE → shape divs; FRAME, GROUP, COMPONENT, INSTANCE → container divs with children; LINE, VECTOR → styled divs; BOOLEAN_OPERATION → div.
Design properties
Solid fills → backgroundColor; Gradient fills → CSS linear/radial-gradient; Strokes → border; Drop/inner shadow effects → box-shadow; Opacity, cornerRadius, typography, font weight, italic, letter-spacing — all preserved.
Fallback inputs

If no Figma data is found, the paste handler checks for: SVG text (via image/svg+xml or text/plain starting with <svg) → placed as an img data URI. Image files (PNG/JPEG/GIF/WEBP) → placed as an img element. Internal builder clipboard → duplicate elements.

AI Generation
§17

AI features use Google Gemini 2.5 Flash via the @google/generative-ai SDK. All AI calls return structured JSON that maps directly to the builder's data model.

Full site generation
Enter a business name and tagline → Gemini generates a complete multi-page website with all sections, copy, and styles. Creates the BuilderProject document with all pages and blocks.
Page generation
Within an existing project, generate all content blocks for a specific page using the business context already stored in the project.
Block regeneration
Regenerate a single block (hero, features, testimonials, etc.) with fresh content while keeping surrounding blocks unchanged. Optional extra context prompt supported.
Element generation
Generate individual elements on the free canvas from a prompt. Returns an ElementNode tree placed at the cursor position.
Animation generation
AI suggests and applies animation configurations to selected elements — entrance, hover, and scroll-triggered animations.
Element animation
Via the motion section in the properties panel, AI can suggest animation parameters (duration, easing, delay, keyframes) for the selected element type.

Export System
§19

The export modal lets users download their built pages as production-ready code. All exports are generated server-side and delivered as zip archives.

HTML + CSS
A flat index.html with an inline <style> block and a companion styles.css. Clean, semantic markup generated from the element tree.
Next.js
A complete Next.js App Router project scaffold with page components, layout, and globals.css. Ready to npm install && npm run dev.
Laravel
A Laravel Blade template project with the page markup converted to Blade views and CSS in the public assets directory.
Generation pipeline

The element tree is traversed by lib/generateHTML.ts and lib/generateCSS.ts. Each ElementNode is rendered to HTML using its tag, content, attrs, and a generated class name. The Styles objects are converted to CSS rules by lib/stylesToCSS.ts, handling responsive breakpoints for tablet/mobile overrides. The output is zipped by Archiver and streamed back to the browser.

Publishing & Domains
§20

Frames can be published as live pages visible to the public without any export step.

Subdomain publishing
Each project gets a unique URL at /site/[projectId] on the platform domain. Pages are rendered server-side from the stored element tree.
Custom domain
Users can add their own domain. The system generates a DNS TXT verification token (_lhrweb-verify.domain = token). After DNS verification, the domain routes to the project.
Slug routing
Each published page has a slug. The /by-slug/:slug API resolves pages by slug, and /by-domain/:domain resolves by custom domain for CDN/proxy routing.
Analytics
Basic analytics endpoint at GET /api/builder/analytics — tracks page views against published sites.
Subscriptions
§21

Stripe-powered subscription system with two plans. The subscriptionCheck middleware guards builder routes from unauthenticated or unsubscribed users.

Starter Plan
Entry-level access to the builder with basic AI generation credits and standard export.
Pro Plan
Full access including custom domains, higher AI generation limits, and all export formats.
Stripe integration
  • Stripe Checkout Session created server-side with plan metadata
  • Webhook endpoint receives checkout.session.completed events
  • Subscription document created/updated in MongoDB on successful payment
  • Payment confirmation email sent via Nodemailer
  • Webhook events deduplicated by stripeEventId to prevent replay
